AWS IoT Core Custom Endpoint (ohne https://)

Hinweis: AWS IoT benötigt ein eigenes X.509-Zertifikat, das im tedge-Konfigurationsordner hinterlegt sein muss. Der Endpoint ist der Custom Endpoint aus der AWS IoT Core-Konsole.

Azure IoT Hub-Hostname (ohne https://)

Hinweis: Azure IoT Hub nutzt das thin-edge.io-Gerätezertifikat für die Authentifizierung. Das Zertifikat muss im Azure IoT Hub als Device registriert sein.

Port 9883 aktiviert den Cumulocity MQTT-Service (c8y.mqtt_service.enabled = true).
Port 8883 nutzt direkte MQTT-Verbindung (c8y.mqtt_service.enabled = false).

Das Ändern des MQTT-Ports startet den Cumulocity-Mapper und zugehörige Dienste neu. Eine kurze Verbindungsunterbrechung zur Cloud ist normal.
