### Rust Dependencies

This application is built using Rust and includes numerous open-source Rust crates (libraries). 
All dependencies are listed in the `Cargo.lock` file in the source repository.

Major dependencies include:
- tokio (MIT License) - Async runtime
- serde (MIT/Apache-2.0) - Serialization framework
- rumqttc (Apache-2.0) - MQTT client
- reqwest (MIT/Apache-2.0) - HTTP client
- rustls (Apache-2.0/ISC/MIT) - TLS implementation
- axum (MIT) - Web framework
- clap (MIT/Apache-2.0) - CLI parsing
